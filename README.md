# 日経連動性トラッカー

日経平均先物と個別銘柄の連動性を色分けで記録・閲覧する単一 HTML アプリです。

- `nikkei_correlation_tracker.html` をブラウザで開くだけで使えます。
- データはブラウザの localStorage に保存されます（JSON の書き出し・読み込みでバックアップ可能）。
- サーバー不要で、日経データ（始値・高値・安値・終値・サマリ）と手動スコアの記録・閲覧ができます。

## 相関の自動計算（オプション）

入力タブの「相関計算」は、別途ローカルサーバー（`http://localhost:8765/correlate`）が必要なオプション機能です。
サーバーは本リポジトリに含まれていません。サーバーが無くても、それ以外の機能はすべて利用できます。
